2D Structure vs. Vector Unrolling

Limitations of MLPs on Image Data

Why Flattening Breaks Images
  • Spatial Adjacency Destruction: Flattening a 2D image into a 1D vector breaks pixel adjacency.
  • Loss of Translation Equivariance: MLPs must relearn weights for every position if an object shifts.
  • Coordinate Independence: Convolutions keep the 2D grid, applying the same kernel everywhere.
Flattening a 2D Matrix (H x W) into a 1D Array Destroys Vertical Adjacency

Networks as Function Composition

Layer-wise Non-Linear Transformations

Hierarchical Manifold Untangling: Low-Level Edges -> Mid Motifs -> Class Concepts
How Layers Compose
  • Composite Mapping: A network is a composite function F(X;Θ) = f_L ∘ ... ∘ f_1(X).
  • Layer Transformation: Each layer applies an affine map plus non-linearity: f_l(h) = σ(W_l h + b_l).
  • Separable Latent Space: Layers gradually reshape pixels into a linearly separable space.

The Linear Collapse Proof
  • The Linear Collapse Theorem: With linear activations, F(X) collapses to one effective linear map.

  • Manifold Folding via ReLU: Non-linear activations fold space into piecewise-linear decision regions.

Sliding Window Mechanics
  • Mathematical Formulation: Cross-correlation: S(i,j) = ΣΣ I(i+m,j+n)K(m,n) + b.

Two Core CNN Axioms

Inductive Biases That Cut Parameters

Core Inductive Biases
  • Axiom 1: Local Connectivity: Each neuron connects only to a local K×K patch, not the full image.
  • Axiom 2: Weight Sharing: The same filter weights are reused everywhere, giving translation equivariance.
  • Statistical Efficiency: The network learns a small set of shared feature detectors, not millions of weights.
Translation Equivariance: Shifting Input Shifts Output Maps Identically

Stride & Padding

Controlling Output Size

Same Padding: Zero-Boundary Padding Preserves Spatial Grid Dimensions
Stride S = 2: Skips Intermediate Pixels for Spatial Subsampling
Hyperparameter Control
  • Output Dimension Equation: Output size: H_out = ⌊(H_in − K + 2P) / S⌋ + 1.
  • Padding Modes: Valid padding (P=0) shrinks output; same padding keeps size unchanged.
  • Stride Subsampling: Stride > 1 skips pixels, shrinking output and growing the receptive field.

Receptive Field Dynamics

3D Tensor Convolutions

Convolving Across Channels and Space

Stanford CS231n Volumetric Convolution: C_in x H x W Convolved into C_out Feature Maps
Multichannel Tensor Flow
  • Tensor Volume Shape: Input (C_in×H×W) is processed by C_out filters, each shaped C_in×K_h×K_w.
  • Channel-Wise Summation: Each filter convolves all input channels, summing into one output map.
  • Channel Expansion: Stacking C_out responses gives the output volume (C_out×H_out×W_out).

A Formula Independent of Image Size

Analytical Parameter Breakdown: (Kernel Area x Input Channels + Bias) x Output Channels
The Parameter Formula
  • Universal Parameter Equation: Params = (K_h·K_w·C_in + 1) · C_out, including one bias per filter.
  • Resolution Independence: Parameter count depends only on kernel size and channels, not image size.
  • Concrete Example: Example: K=3, C_in=64, C_out=128 gives 73,856 parameters.

ReLU and Sparsity

How ReLU Preserves Gradient Flow

ReLU Activation Dynamics
  • The ReLU Definition: f(x) = max(0, x), with derivative 1 for x>0 and 0 for x<0.
  • Vanishing Gradient Cure: Unlike Sigmoid/Tanh, ReLU keeps a constant gradient, enabling 100+ layer training.
  • Induced Sparsity: Zeroing negative values creates sparse activations (~50% active neurons).

ResNet (2015)

Residual Learning With Skip Connections

ResNet Residual Block: Identity Connection H(x) = F(x) + x Providing Direct Gradient Flow
Deep Residual Learning
  • The Degradation Problem: Past ~20 layers, plain networks lose accuracy from vanishing gradients.
  • Identity Skip Highway: Residual form H(x) = F(x) + x lets gradients flow directly to early layers.
  • Superhuman Accuracy: Scaled to 152 layers, winning ImageNet 2015 with 3.57% top-5 error.

Dense Feature Concatenation
  • Full Feed-Forward Connectivity: Each layer connects to all later layers via feature-map concatenation.
